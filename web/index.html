Реальные карты из контроллеров

Постоянный каталог карт, реально декодированных из 25H-событий UNEX 721. Каталог хранится в основном хранилище системы и не зависит от журнала посещаемости.

Автопривязка: если карта уже есть у пользователя в системе, она связывается автоматически по точному series:number. Для новой карты можно выбрать существующего пользователя вручную либо создать отдельного пользователя и затем отредактировать его.

Отчёты посещаемости

Суточный, недельный, месячный отчёт или произвольный диапазон дат. В отчёт входят первый приход, последний уход и состояние пользователя на конец каждого дня.

Выберите период и нажмите «Сформировать».

Автоматическая отправка по расписанию

Используется Bot Token и Chat ID из настроек Telegram. Автоматические отчёты отправляются как текстовый файл.

Что отправляется автоматически: суточный — предыдущие завершённые сутки; недельный — предыдущая календарная неделя (Пн–Вс); месячный — предыдущий календарный месяц.

Поиск карты в EEPROM UNEX 721

Диагностическое чтение командой 12H Read EEPROM. Ничего в контроллер не записывается. Поиск проверяет несколько представлений серии/номера: binary BE/LE, BCD и ASCII, а также частичное совпадение номера карты.

Полный диапазон 0000..FFFF при 9600 бод может читаться несколько минут. Обычный polling событий между блоками сохраняется.

Считать пользователей из контроллера

Чтение выполняется командой 0x87 через общую очередь COM-порта. Данные контроллера не изменяются.

Выгрузка пользователей в контроллеры

Выберите всех или отдельных пользователей и контроллеры назначения. Задание выполняется через общую очередь COM-порта.

Удаление пользователей

Можно удалить выбранных или всех пользователей из программы, из выбранных/всех контроллеров, либо одновременно из обоих мест.

Безопасное комбинированное удаление: при выборе «из системы и контроллеров» локальная карточка пользователя удаляется только после подтверждённого удаления этого пользователя из каждого выбранного контроллера. При ошибке связи пользователь остаётся в системе.
