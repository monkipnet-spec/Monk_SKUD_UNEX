# Third-party protocol reference

Monk_SKUD_UNEX v0.2.0 uses the publicly documented SOYAL H-series Extended Protocol layout and the MIT-licensed `oommgg/Soyal` project as an interoperability reference.

- Project: https://github.com/oommgg/Soyal
- Author listed by that project: Ben Chung
- License: MIT

The Monk_SKUD_UNEX implementation is C++ and is not a verbatim copy of the PHP library. The referenced project was used to verify packet framing, card write/read commands and response field layout.
