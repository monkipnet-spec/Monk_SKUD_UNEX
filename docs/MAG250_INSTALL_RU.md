# MONK SKUD на MAG250

Версия сервера: v0.3.32+

MAG250 не использует Android APK. Для него Monk_SKUD_UNEX отдаёт отдельный лёгкий WebKit-портал:

`http://IP_СЕРВЕРА:8080/mag250/`

## Рекомендуемая установка через меню MAG250

1. Подключить MAG250 и сервер Monk_SKUD_UNEX к одной сети.
2. На компьютере проверить в браузере `http://IP_СЕРВЕРА:8080/mag250/`.
3. На MAG250 открыть системные настройки порталов.
4. Включить внешний/пользовательский портал и указать URL выше.
5. Назвать портал `MONK SKUD` и выбрать его порталом по умолчанию/автозапуска.
6. Сохранить настройки и перезапустить портал или приставку.

Названия пунктов меню могут отличаться в разных прошивках MAG250. Если в операторской прошивке редактирование URL портала заблокировано, потребуется public/custom firmware либо настройка портала через конфигурацию/SSH.

## Что делает портал

- обновляет `/api/monitor` каждые 3 секунды;
- показывает общее количество сотрудников, на объекте/вне объекта и состояние контроллеров;
- показывает сотрудников «НА РАБОТЕ» первыми;
- автоматически прокручивает длинный список по кругу;
- Up/Down на ПДУ прокручивают список вручную;
- OK/Enter немедленно обновляет данные;
- не требует входа администратора и не показывает карты/PIN/пароли.

## Проверка с сервера

```bash
curl -I http://127.0.0.1:8080/mag250/
curl -s http://127.0.0.1:8080/api/monitor | head
```

Ожидается HTTP 200 для портала и JSON от `/api/monitor`.


## Отображение сотрудников (v0.3.37)

Для экрана 1920x1080 автопрокрутка отключена. Сотрудники со статусом «НА РАБОТЕ» остаются крупными сверху; строки «УШЁЛ», «ОТСУТСТВУЕТ» и «ОТКЛЮЧЕН» автоматически уменьшаются по высоте и размеру шрифта, чтобы весь список помещался на одном экране.
